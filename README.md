Python Login System

A simple console-based login system built with Python.

Features
Accepts any non-empty username.
Removes unnecessary spaces from user input.
Checks the password.
Allows up to 3 password attempts.
Displays a welcome message when the password is correct.
Stops after 3 incorrect attempts.
Technologies
Python
How to run
Make sure Python is installed.
Open a terminal in the project folder.

Run:

python login.py
